Map server
TurnPilot downloads the map for each drive from its own map server. The key is stored on the comma and never shown again.
Restart the comma
A Tesla stays on while you're in it, so the comma never restarts by itself. Restart it here to apply an update, a turn signal check or a setting that waits for the next start. Disengage first; it takes about a minute.
Car turn signal
On a verified Tesla the car works its own turn signal for TurnPilot's turns and lane changes. Off, you signal, and TurnPilot asks you at each turn. The check blinks the lamps in Park (or, with Start in Drive, stopped with the brake held): watch the front, side and rear lamps from outside, or film them.
